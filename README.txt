Fight Royale (Godot) — Installer Collection 16D through 19V
==========================================================
Included: 31 original Python installers (16D–16E, 17A–17D, 18A–18C, 19A–19V), plus a PowerShell commands guide.
Excludes 16C and earlier by request. Installer files are preserved byte-for-byte from the previously saved archive and later library files.

How to use:
1. Extract the ZIP into your existing Godot project directory.
2. Open PowerShell in that directory.
3. Follow terminal_commands_16d_to_19v.txt in update order, STARTING FROM THE UPDATE NOT YET APPLIED.
4. Stop and diagnose if an installer errors; do not continue applying subsequent updates.

Important:
- These are project patch/installers, not a complete standalone Godot project.
- Match the source version expected by each patch. Keep backups and consider a clean git working tree.
- The included PowerShell guide contains optional git commits after each successful installer.
- Scripts were syntax-checked for Python, but NOT executed against your Godot project in this environment.
